# Dungeon Route Guide (던전 길잡이)

WoW Forever dungeon route overlay. Opens a semi-transparent map when you enter a dungeon and shows the route, bosses, rares, NPCs and quest spots in order, checks bosses off automatically and shows the next objective.

와우 포에버 던전 공략 길잡이. 던전에 들어가면 반투명 지도에 진행 경로와 우두머리·희귀 몹·NPC·퀘스트 장소를 순서대로 보여주고, 보스를 잡으면 자동으로 체크합니다.

- `/drg` toggle map · `/drg go` entrance arrow · `/drg icon` screen icon · `/drg help`
- 18 dungeons (route data referenced from wowf.io guides)
- Maps: Atlas Classic (GPL-2.0). See `CREDITS.txt`.
