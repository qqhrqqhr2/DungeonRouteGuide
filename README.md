# DungeonRouteGuide v1.0.8

와우 포에버용 던전 길잡이. 18개 던전, 29개 지도 페이지, 내부 목표 125개 참고 위치를 포함합니다.
모든 지도 페이지에 미니맵 타일을 넣었습니다. 게임 클라이언트에서의 실행과 실제 스폰 위치 확인은 아직 하지 못했습니다.

## 표시와 한국어 퀘스트 수정

퀘스트 이름 106개를 한국어로 표시합니다. 클라이언트에서 한국어 이름을 제공하면 그 이름을 우선 사용합니다.
개발용 상태 문구와 외부 공략 사이트명은 게임 화면에 표시하지 않습니다.

## 아이콘 복구 (dev14)

기존 지도·경로 모양의 애드온 아이콘 파일을 다시 포함했습니다. 화면 버튼과 애드온 목록이 같은 원래 아이콘을 사용합니다.

## 수도원 구역 판별 수정 (dev13)

- 수도원의 네 구역은 인스턴스 번호 189를 공유합니다. 구역을 읽지 못했을 때 묘지를 선택하던 기본값을 제거했습니다.
- 소구역 → 미니맵 구역 → 전체 구역 순서로 확인합니다. 앞의 값이 없거나 읽기 제한 상태여도 뒤의 값을 확인합니다.
- 같은 입장에서 확인한 구역은 잠깐 이름이 없어져도 유지하며, 새 입장·로딩 때는 이전 구역과 직접 선택값을 초기화합니다.
- 입장 직후 구역명이 늦게 갱신되는 경우 다시 확인합니다. 판별 대기 중의 구역 변경 이벤트도 처리합니다.
- 자동 판별이 안 되면 수도원 4구역 선택창이 열립니다. 지도 제목의 던전 선택도 현재 수도원 구역을 직접 지정합니다.
- 도서관을 직접 지정하려면 `/drg wing 도서관` 또는 `/drg wing smlib`를 사용합니다. `/drg wing auto`로 자동 판별로 돌아갑니다.
- 직접 선택은 다음 입장·로딩 전까지 유지됩니다. 실제 게임에서의 이번 오류 해결 확인은 아직 하지 못했습니다.

## 설치

1. 와우를 완전히 종료합니다.
2. 기존 Interface/AddOns/DungeonRouteGuide 폴더를 이 ZIP 안의 DungeonRouteGuide 폴더로 교체합니다.
3. 캐릭터 선택 화면에서 애드온을 켜고 접속한 뒤 /drg 명령으로 엽니다.

진행 기록을 지울 필요는 없습니다. 이전 지도에 직접 찍었던 편집 좌표는 새 지도와 분리합니다.

## 사용

- 지도 위 마우스 휠: 1배부터 5배까지 확대·축소합니다.
- 확대 상태에서 지도 끌기: 화면을 이동합니다. 기본 배율에서는 기존처럼 창을 이동합니다.
- 오른쪽 아래 '전체' 또는 배율 버튼: 전체 지도에 다시 맞춥니다.
- 목표 클릭: 해당 층으로 이동하고 선택합니다. 전리품·모델 정보가 있는 목표는 상세 카드가 열립니다.
- 목표 우클릭: 완료 표시 또는 완료 취소입니다.
- 파란 연결 번호 클릭: 연결된 층을 엽니다. 마우스를 올리면 목적지 설명이 나타납니다.
- 무작위 출현 목표 선택: 다른 출현 후보 지점도 표시합니다.
- 지도 위 층 선택 버튼: 필요한 층을 직접 선택합니다.
- 창 상단을 끌어 위치를 바꿀 수 있습니다.

## 지도 기능 (dev12)

- 투명 여백을 제외한 실제 지도·목표 범위에 자동 맞춤을 적용했습니다.
- 모든 페이지를 같은 크기의 정사각형 표시 영역에서 볼 수 있습니다.
- 목표와 층 연결 번호의 클릭 영역을 겹치지 않게 배치했습니다. 옮겨진 표식은 선으로 실제 위치를 가리킵니다.
- 층 연결의 긴 이름은 마우스를 올렸을 때 보여 지형을 가리지 않도록 했습니다.
- 죽음의 폐광 철갑 동굴의 배·동굴 지형을 공식 클래식 미니맵으로 보완했습니다.
- 성채 감옥 방의 공식 미니맵을 복구하고, 현재 안뜰 범위에 해당하는 공식 지형 미니맵만 표시합니다.
- 성채의 방 번호가 서로 다른 과거 타일은 사용하지 않았습니다.
- 가시덩굴 구릉의 투텐카쉬·역병아귀 이벤트 소환 참고 위치를 추가했습니다.
- 광기의 매글리시는 던전 바깥 목표이므로 내부 지도에 표시하지 않습니다. 입장 전 안내는 유지합니다.
- 무손실 TGA 257개, 타일 주변 2픽셀 여백, 버전별 MinimapTiles_v12 경로를 사용합니다.

## 지도 방향과 자료 범위

28개 지도 페이지는 세계 북쪽이 위입니다. 달라란 하수도 1개는 가이드 방향이며 실제 북쪽은 미확인입니다.
회전 미니맵 설정을 사용하는 경우 고정 북쪽 지도와 미니맵 방향이 달라질 수 있습니다.
건물과 세계 축이 다른 성채·가시덩굴 지도는 북쪽 기준에서 비스듬해 보일 수 있습니다.
지형 색·나무·지붕·벽은 클라이언트 미니맵에 들어 있는 내용입니다. 임의로 통로나 바닥을 그리지 않았습니다.

기본 자료: Forever Beta 1.60.1.70338의 미니맵·건물 구조·배치.
보완 자료: 공식 Classic Era 1.15.9.70003의 일부 미니맵. 지도 타일 번호·건물 배치·감옥 방 경계를 현재 자료와 대조했습니다.
안뜰은 현재 courtyard 그룹의 경계 안에서만 해당 지형 미니맵을 표시합니다.
목표 위치는 기존 클래식 DB·이벤트 스크립트와 공략 자료 공략을 현재 지도에 옮긴 참고 좌표입니다.
현재 포에버 서버에서의 변경·순찰·실제 출현은 이 검사만으로 확정하지 않습니다.
