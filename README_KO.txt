Dungeon Route Guide (던전 길잡이) 0.2.0 - 와우 포에버용

[무엇을 하나요]
- 화면 아이콘(지도 모양): 던전 밖에서도 왼쪽 클릭으로 공략 지도를 열고, 오른쪽 클릭으로 입구 안내를 켭니다.
  밖에서 열면 내 레벨에 맞는 던전이 먼저 나오고, 창 위쪽 < > 로 다른 던전을 볼 수 있어요. 끌어서 옮길 수 있습니다.
- 던전에 들어가면 반투명 지도 창이 자동으로 열립니다 (Atlas 던전 지도).
- 지도 위에 진행 순서대로 경로선을 그립니다. 노란 선 = 지금 가야 할 길, 흰 선 = 이후, 회색 = 지나온 길.
- 보스를 잡으면 자동으로 체크됩니다. 내 대상·파티원 대상·이름표·마우스를 올린 시체·전투 종료 이벤트·
  전리품 출처를 보고, 전투가 끝나면 한 번 더 훑어서 놓친 처치를 잡습니다.
  그래도 안 되면 목록이나 지도 표식을 오른쪽 클릭하면 됩니다 (예비용).
- 진행 초기화: 다 깬 던전에 다시 들어오거나, 인스턴스가 초기화된 것(새 몹)을 감지하면 처음부터 시작합니다.
  죽어서 유령으로 나갔다 오는 경우처럼 같은 인스턴스면 진행이 유지됩니다.
  던전 밖에서 "인스턴스 초기화" 메시지가 뜨면 그 던전 진행도 미리 초기화합니다.
- 화면 위쪽 "다음 목표" 막대: 다음 보스와 공략 한 줄. 보스를 대상으로 잡으면 그 보스 팁으로 바뀝니다.
- 희귀 몹이 이름표에 보이면 경고 문구와 소리로 알려줍니다.
- 입구 안내: 필드에서는 던전 입구까지 화살표와 거리를 보여줍니다.
- 퀘스트 탭: 던전 퀘스트의 완료/진행 중/미수락 상태와 받는 곳.

[지원 던전 18개 (wowf.io 공략 기준)]
성난불길 협곡, 영주의 전당*, 통곡의 동굴, 죽음의 폐광, 로데론의 폐허*, 그림자송곳니 성채,
검은심연의 나락(지도 3장), 스톰윈드 지하감옥, 발굴 현장: 저습지*, 달라란**, 놈리건, 가시덩굴 우리,
붉은십자군 수도원 묘지·도서관·무기고·대성당, 가시덩굴 구릉, 울다만
 * 포에버 신규 던전: 지형 그림 없이 상대 위치만 표시
 ** 달라란: 지도 자료가 없어 목록만

[지도 표식]
초록 원 = 입구, 빨강 = 우두머리, 보라 = 희귀 몹, 파랑 = NPC, 노랑 = 퀘스트 장소(물건·할 일)
노란 "!" = 퀘스트 관련, 옅은 작은 원 = 다른 출현 지점, 회색 마름모 = 층 이동 지점
지도 위 번호는 진행 순서입니다(Atlas 원래 번호는 가려 둡니다).
제목을 클릭하면 던전 목록이 열리고, 지도가 여러 장인 던전은 지도 아래 버튼으로 넘깁니다.
오른쪽 목록 탭: 경로(진행 순서·팁) / 퀘스트(완료·진행 중·미수락) / 준비(주의 사항·입구 좌표)

[명령어]
/drg               지도 창 열기/닫기
/drg hud           다음 목표 막대 켜기/끄기
/drg icon          화면 아이콘 보이기/숨기기
/drg next / undo   (예비용) 다음 단계 직접 완료 / 되돌리기
/drg reset         진행 초기화
/drg go            지금 보고 있는 던전의 입구 안내 (/drg go stop 으로 끄기)
/drg entrance set  입구 좌표가 틀리면, 포털 앞에 서서 입력하면 그 위치로 저장
/drg edit          경로 편집 모드 (목록에서 단계 선택 후 지도 클릭)
/drg export        편집한 경로를 복사 가능한 텍스트로 보기
/drg debug         던전 인식 정보 출력 (문제가 있을 때 결과를 알려주세요)
단축키 설정: 게임 메뉴 > 단축키 > 애드온 > Dungeon Route Guide

[게임에서 확인할 것]
1. 던전 입장 시 지도 창과 다음 목표 막대가 자동으로 뜨는지
2. 보스를 잡았을 때 자동 체크되는지 (안 되면 어떤 보스였는지)
3. 입구 안내 화살표 방향이 맞는지, 입구 좌표가 맞는지
4. 수도원 묘지에서 /drg debug 결과 (날개 구분용)
